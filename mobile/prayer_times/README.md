# مواقيت الصلاة

تطبيق Android أصلي مكتوب بـFlutter وDart. لا يستخدم موقعًا أو WebView، ولا يحتاج اتصالًا بالشبكة أثناء الاستخدام. لا يحتوي على صوت أذان. يتضمن جدول «مواقيت الصلاة لقرية حوض 6» الذي زوده المستخدم، وجدول «مواقيت الصلاة لمنطقة العباسي» المحوّل من ملف PDF بعد مطابقة جميع أوقاته.

## الحالة الحالية

- شاشة عربية RTL تستلهم الصورة المرفقة، وتتكيف بين العرض الأفقي والعمودي.
- ساعة الجهاز، خلفية مسجد مرسومة داخل Flutter، خط Amiri مضمّن محليًا، وزر إعدادات صغير أعلى يسار الشاشة.
- إدارة محلية للمناطق، تعديل مواقيت أي يوم، استيراد جدول JSON، ونسخ احتياطي واستعادة.
- عداد مركزي واحد يعمل كل ثانية، مع عداد الإقامة والانتقال من العشاء إلى فجر اليوم التالي.
- تخزين دائم داخل مجلد بيانات التطبيق، دون طلب إذن الإنترنت.
- التاريخ الهجري بحساب مدني محلي تقريبي مع إزاحة يومية قابلة للتعديل ±3 أيام؛ قد يختلف عن الرؤية المحلية.
- تفعيل الشاشة الدائمة وملء الشاشة وخيار محاولة التشغيل بعد إقلاع Android، مع احترام قيود النظام والمصنّع.

جدول قرية حوض 6 مضمّن محليًا، ويمكن اختياره وحفظه من قائمة المناطق في الإعدادات. ملف `assets/data/hawd6-prayer-times.json` هو ملف المستخدم دون تعديل على أوقاته؛ الفجر الأول قبل الثاني بـ15 دقيقة. الجدول بلا سنة ويتكرر حسب اليوم والشهر، بما فيه 29 شباط للسنوات الكبيسة. المواقيت المعدلة لتاريخ محدد تتقدم على الجدول السنوي. تحفظ النسخ الاحتياطية الجدول السنوي والتعديلات معًا.

يمكن إضافة ملفات مناطق أخرى إلى قائمة `bundledScheduleAssets` وتسجيلها في `pubspec.yaml`، أو استيراد ملفات المستخدم السنوية التي تحتوي `name` و`months` مباشرة. تبقى المناطق والإعدادات المحفوظة سابقًا عند إضافة جدول مضمّن جديد.

جدول العباسي مضمّن في `assets/data/al-abbasi-prayer-times.json` ويظهر باسم «مواقيت الصلاة لمنطقة العباسي» في الإعدادات. يحتوي على 366 يومًا وسبعة مواقيت يومية بنظام 12 ساعة، بما فيها الفجر الأول والثاني كما وردا في PDF. ينطبق عليه التكرار السنوي نفسه دون افتراض سنة محددة. لا تؤدي إضافته إلى تغيير المنطقة المختارة سابقًا؛ يختاره المستخدم ويحفظه من الإعدادات.

ملف `assets/data/prayer-times-template.json` قالب فقط، ويمنع التطبيق استيراده قبل وضع الأوقات الحقيقية وتغيير `"template": true` إلى `false`.

## صيغة ملف المواقيت

```json
{
  "format": "mwaqit-prayer-times",
  "schemaVersion": 1,
  "template": false,
  "region": {
    "id": "al-abbasi",
    "name": "ناحية العباسي"
  },
  "years": [
    {
      "year": 2026,
      "months": [
        {
          "month": 10,
          "days": [
            {
              "day": 11,
              "prayers": {
                "fajrFirst": "04:20",
                "fajrSecond": "04:45",
                "sunrise": "06:05",
                "dhuhr": "11:55",
                "asr": "15:15",
                "maghrib": "17:40",
                "isha": "19:05"
              }
            }
          ]
        }
      ]
    }
  ]
}
```

تُكتب الأوقات بنظام 12 ساعة، مثل `"4:35 AM"` أو `"4:35 م"`. يقبل التطبيق أيضًا وقتًا بلا لاحقة مثل `"4:35"` ويستدل على الصباح أو المساء من ترتيب مواقيت اليوم، كما يقبل صيغة 24 ساعة القديمة عند استيراد ملفات سابقة. يجب أن توجد البنود السبعة لكل يوم. يمكن جمع أكثر من سنة في `years`، وتُستورد كل منطقة بصورة مستقلة بمعرّف `id` ثابت. يعرض التطبيق الأوقات بنظام 12 ساعة ويصدر النسخ الاحتياطية بالصيغة نفسها.

## تجهيز Android والبناء

تحتاج إلى Flutter stable وAndroid SDK مع Android SDK Platform حديث. من جذر المستودع:

```bash
bash scripts/bootstrap-prayer-times-android.sh
cd mobile/prayer_times
flutter pub get
flutter analyze
flutter test
flutter build apk --release
flutter build appbundle --release
```

ملفات المنصة الأصلية وقالب Android موجودة في `android_template/`. ينشئ سكربت التجهيز مشروع Android القياسي بـFlutter ثم يركّب القالب الذي يضيف استقبال إقلاع الجهاز. يعيد تشغيل السكربت تركيب ملفات Android هذه، لذلك لا تعدّل القالب وحده بعد التجهيز.

## بناء تلقائي عبر GitHub Actions

يوجد workflow في `.github/workflows/prayer-times-android.yml`. بعد رفع المستودع إلى GitHub وتشغيله من تبويب **Actions** (أو بعد دفع تغيير داخل التطبيق)، ينفذ `flutter pub get` والتحليل والاختبارات، ثم يبني APK وAAB ويرفعهما كملفين قابلين للتنزيل من صفحة تشغيل الـworkflow.

للتثبيت المباشر على الهاتف أو Android TV Box نزّل `app-release.apk`، وافتحه على الجهاز واسمح بالتثبيت من المصدر الذي نزّلت منه عند ظهور مطالبة Android. ملف AAB مخصص عادةً لقنوات التوزيع، وليس للتثبيت المباشر بالطريقة نفسها.

للتشغيل التلقائي بعد الإقلاع، يجب فتح التطبيق مرة واحدة بعد تثبيته، ثم تفعيل الخيار من الإعدادات. Android وبعض أجهزة TV Box قد تمنع بدء الواجهة من الخلفية؛ الخيار يحاول ذلك فقط ولا يتجاوز قيود النظام. التطبيق لا يستطيع تصحيح ساعة الجهاز من تلقاء نفسه.
